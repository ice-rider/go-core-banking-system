# Архитектура

## Паттерн
Микросервисная архитектура, database-per-service.

## Внутреннее взаимодействие
gRPC (protobuf3).

## Внешнее взаимодействие
REST API (Gin).

## Сервисы

### API Gateway
- Технология: Go, Gin
- Функция: приём HTTP-запросов, аутентификация/авторизация, валидация, маршрутизация во внутренние gRPC-вызовы

### Account Service
- Технология: Go, gRPC, PostgreSQL
- Функция: управление жизненным циклом счетов (создание, блокировка, закрытие), хранение баланса
- БД: выделенный инстанс PostgreSQL

### Transaction Service
- Технология: Go, gRPC, PostgreSQL, RabbitMQ
- Функция: обработка переводов, оркестрация Saga, ведение журнала транзакций
- БД: выделенный инстанс PostgreSQL

### Веб-клиент
- Технология: React
- Функция: прототип для демонстрации работы бэкенда

## Паттерны распределённых транзакций
- **Saga** (оркестрация) с компенсирующими транзакциями
- **Пессимистичные блокировки** (SELECT ... FOR UPDATE) для предотвращения race conditions
- **Идемпотентность** через idempotency-key

## Схема потока перевода
```
1. PENDING: резервирование средств на счёте отправителя
2. Зачисление средств на счёт получателя
3. COMMIT: подтверждение списания у отправителя
4. При ошибке — компенсирующие транзакции (откат)
```
