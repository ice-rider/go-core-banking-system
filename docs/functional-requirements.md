# Функциональные требования

## Account Service
- Создание счёта с уникальным ID и начальным балансом
- Получение информации о счёте и текущем балансе
- Блокировка и разблокировка счёта

## Transaction Service
- Перевод средств между двумя счетами
- Пессимистичная блокировка (SELECT ... FOR UPDATE)
- Паттерн Saga:
  - Шаг 1: резервирование (PENDING)
  - Шаг 2: зачисление получателю
  - Шаг 3: коммит у отправителя
  - Компенсация при ошибке
- Идемпотентность через idempotency-key

## Асинхронные события
- Публикация событий транзакций в RabbitMQ (успешные/неуспешные)

## Нефункциональные
- Eventual Consistency через Saga
- Идемпотентность финансовых операций
- Отказоустойчивость (circuit breaker, retry, exponential backoff)
- Безопасность (нет секретов в коде, TLS для gRPC)
